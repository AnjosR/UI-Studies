## ✨ Sobre este repositório

Este é o meu espaço para **aprender, experimentar e documentar** tudo o que envolve a construção de interfaces modernas e experiências visuais na web.

Aqui você encontra código de cursos, testes, protótipos e aquelas experimentações do tipo _"será que dá pra fazer isso?"_. A ideia é evoluir de interfaces estáticas para experiências **interativas, animadas e tridimensionais**.
